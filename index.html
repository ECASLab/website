Who are we?

The Efficient Computing Across the Stack Lab (ECAS Lab) is a research and innovation space at the Costa Rica Institute of Technology (TEC). Our team is composed of students and researchers dedicated to exploring the intersection between hardware and advanced software.

In the laboratory, we have various assistants and student projects from the Computer Engineering, Computer Science, and Electronic Engineering programs. All of this is supported by professors and researchers with years of academic and professional experience.

Location: Costa Rica Institute of Technology (TEC).

Projects

Explore our research and development initiatives. Each project reflects our commitment to technological innovation, solving complex problems through advanced hardware and software design.

HLS-Based Reconfigurable Nonlinear Function Interpolators for Embedded Systems

This project focuses on the design and synthesis of highly efficient hardware interpolation blocks using High-Level Synthesis (HLS) methodologies. Its goal is to accelerate complex nonlinear functions with high precision and minimal resource consumption in reconfigurable devices.

View Repository

Design and Synthesis of Customizable RISC-V Softcore Processors Using HLS

Consists of the implementation of processing cores (softcores) based on the open RISC-V instruction set, entirely developed through High-Level Synthesis (HLS) flows for custom embedded microcontrollers.

View Repository

PyTorch FPGA Configurable Interface

Development of a configurable Python interface enabling the integration of FPGA hardware accelerators with PyTorch AI models, validated with LeNet-5 on MNIST and MobileNetV2 on ImageNet-1K.

View Repository

Specialized Tensor Unit Architectures for Deep Learning Acceleration on FPGAs

Explores hardware-software co-design for optimized tensor processing units in FPGAs, focusing on mixed-precision matrix multiplication and sparse computing.

View Repository

Exploration and Design of an Architecture for Large Language Models (LLMs) Acceleration on FPGAs

Research and development of an efficient and adaptable hardware-software architecture for Large Language Models (LLMs) inference on FPGA devices, targeting edge computing.

View Repository

SLAM Algorithms Acceleration via Configurable FPGA Unit Design for Edge Mechatronic Systems

This project investigates and develops a hardware/software co-design solution to accelerate computationally critical stages of Simultaneous Localization and Mapping (SLAM) algorithms on low-cost FPGA systems using High-Level Synthesis (HLS) and fixed-point arithmetic optimization.

View Repository

High-Efficiency Transprecision Floating-Point Unit for Machine Learning Training and Inference Acceleration

This project proposes the design and co-design of a Floating-Point Unit (FPU) with dynamic configuration and fine granularity over operand lengths. Integrating SIMD vector capabilities, it optimizes AI workloads and serves as an advanced design space exploration platform in RISC-V architectures.

View Repository

Development of Reconfigurable Interpolation Units Based on TLUT and Horner Scheme

Focuses on the design and implementation of arithmetic blocks optimized using truncated lookup tables (TLUT) and Horner's polynomial evaluation scheme to accelerate nonlinear functions and mathematical approximations with reduced hardware resource consumption.

View Repository

Integration of Special Units Within RISC-V Architectures

Consists of the RTL-level incorporation and validation of coprocessors and specialized functional units (such as transprecision FPUs and tensor units) within an open-source RISC-V processor core, evaluating custom instruction decoding and overall performance impact.

View Repository

RISC-V Architecture with Dynamically Reconfigurable Nonlinear Function Accelerator (CAMTA)

This project presents CAMTA (Configurable Multi-Region Activation Unit), a high-performance, low-power hardware architecture for efficient nonlinear function acceleration in AI workloads. Using multi-region polynomial approximation, Horner's rule, and a pipelined datapath, it allows runtime configuration of coefficients, region limits, and symmetry modes (such as GeLU, tanh, sigmoid, Swish/SiLU) without hardware resynthesis, validated on AMD Alveo U55C FPGAs and edge ASIC flows.

View Repository

RISC-V Architecture Power Consumption Measurement System on FPGA

Presents the design, integration, and validation of an instruction classifier module inside the CV32E40P RISC-V pipeline (PULPissimo SoC on Nexys A7-100T FPGA). It deterministically counts retired instructions across 13 categories exposed via CSR registers, paired with an INA228 high-precision power measurement bench and validated against BEEBS workloads with an RMSE error under 0.13%.
