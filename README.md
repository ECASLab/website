# website

Sitio web del ECAS Lab. Los estilos usan Tailwind CSS y se compilan a `styles.css`.

```bash
npm install      # solo la primera vez
npm run dev      # mientras editas: regenera styles.css al guardar
npm run build    # antes de hacer commit
```

Se debe realizar commit de `styles.css` junto con los cambios; no editar a mano.
